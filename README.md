# Цифровой двойник экспорта Республики Беларусь (Пилот: Машиностроение)

Программно-аналитический комплекс предиктивной аналитики и имитационного моделирования экспорта машиностроительной отрасли Республики Беларусь.

Фокусные предприятия:
* **ОАО «МТЗ»** — Минский тракторный завод (ТН ВЭД 8701)
* **ОАО «БЕЛАЗ»** — Карьерные самосвалы и спецтехника (ТН ВЭД 8704)
* **ОАО «МАЗ»** — Грузовые автомобили и тягачи (ТН ВЭД 8704)
* **ОАО «Амкодор»** — Дорожно-строительная и лесозаготовительная техника (ТН ВЭД 8429)

---

## Четырехуровневая архитектура

1. **Уровень сбора и интеграции первичных данных (Data Ingestion Layer)**
   * Синтетический генератор и конвейер загрузки 4 гетерогенных потоков данных:
     * Электронные таможенные декларации (ГТД).
     * Телематика погранпереходов и портов (GPS/ГЛОНАСС: «Козловичи», «Каменный Лог», «Красная Горка», терминал «Колядичи», морской порт «Бронка»).
     * Банковский реестр паспортно-валютных сделок и дебиторской задолженности.
     * Мировые товарно-сырьевые котировки (LME Steel HRC, LME Copper, индекс фрахта Baltic/WCI, курсы USD/BYN, RUB/BYN, CNY/BYN).
   * Высокоскоростное аналитическое хранилище на базе **DuckDB** и **Apache Parquet**.

2. **Аналитический уровень предиктивного ядра (Predictive Core Layer)**
   * Автоматический Feature Engineering (опережающие индикаторы объема техники в пути, лаги курсов валют, скользящие средние, сезонные гармоники Фурье).
   * Ансамбль моделей машинного обучения: **XGBoost Regressor + Regularized Ridge Trend Baseline**.
   * Расчет доверительных коридоров прогноза (95% Confidence Intervals).
   * Средняя точность по отрасли: **MAPE < 8.5%**, **WAPE < 8.2%**, **R² > 0.70**.

3. **Сценарный уровень имитационного моделирования (Simulation & Scenario Layer)**
   * Движок стресс-тестирования внешних шоков (What-If Sandbox):
     * *Логистический шок:* закрытие пунктов пропуска, удорожание контейнерного фрахта, рост задержек.
     * *Сырьевой шок:* рост мировых цен на сталь LME, давление на маржинальность.
     * *Тарифно-валютный шок:* девальвация российского рубля, повышение ставок утильсбора в РФ.
     * *Диверсификационный сценарий:* рост поставок в Азию и Африку по коридору «Север-Юг».

4. **Уровень интерфейсов и поддержки решений (Decision Support Layer)**
   * Интерактивное веб-приложение на **Streamlit & Plotly**:
     * Макро-аналитика для органов госуправления (Минпром, Минэкономики, МИД).
     * Оперативная GIS-карта транспортных узлов и очередей.
     * Интерактивная песочница со слайдерами параметров стресс-теста в реальном времени.
     * Автогенерация аналитических справок для руководства.

## Структура проекта

```
belarus_export_twin/
├── data/
│   ├── raw/                 # Parquet-файлы первичных потоков
│   ├── processed/           # Агрегированные временные ряды для ML
│   └── export_twin.duckdb   # Реляционная аналитическая база данных DuckDB
├── models/
│   ├── baseline_forecast.parquet    # Базовый 12-месячный прогноз
│   ├── precomputed_scenarios.parquet# Результаты стресс-тестов
│   ├── metrics_summary.json         # Метрики WAPE, MAPE, R²
│   └── ensemble_*.joblib            # Веса обученных моделей по заводам
├── src/
│   ├── config.py            # Конфигурация параметров, кодов ТН ВЭД, узлов
│   ├── ingestion/           # Уровень 1: генератор и ETL
│   ├── predictive/          # Уровень 2: фичи, ML-модели, валидация
│   ├── simulation/          # Уровень 3: сценарный движок и стресс-тесты
│   └── ui/                  # Уровень 4: интерактивный дашборд Streamlit
├── tests/                   # Набор автоматических тестов pytest
├── run_pipeline.py          # Мастер-скрипт полного цикла
└── README.md
```

## Быстрый запуск

### 1. Запуск полного пайплайна (генерация, обучение, симуляция, тесты)
```powershell
& .venv\Scripts\python.exe run_pipeline.py
```

### 2. Запуск интерактивного аналитического дашборда
```powershell
& .venv\Scripts\python.exe -m streamlit run src/ui/dashboard.py
```
После запуска откройте в браузере: `http://localhost:8501`.

### 3. Запуск тестов
```powershell
& .venv\Scripts\pytest.exe tests/
```
